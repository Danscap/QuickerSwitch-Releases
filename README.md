# QuickerSwitch Releases

Signed Windows installers for QuickerSwitch, by Shortwork Labs (DAYDREAM PRODUCTS LLC).

Download the installer from the [latest release](https://github.com/Danscap/QuickerSwitch-Releases/releases/latest) and run it. To update, run a newer installer over your current installation: your settings and license are kept.

Each release also lists the installer's SHA-256 checksum in `SHA256SUMS.txt`.
